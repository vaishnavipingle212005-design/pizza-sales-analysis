# Pizza Sales Analysis Dashboard

## Project Overview
This project analyzes pizza sales data using Microsoft Excel and Power BI to understand sales performance, customer ordering patterns, and product popularity.

## Tools & Technologies
- Microsoft Excel
- Power BI
- DAX
- Data Visualization

## Key Performance Indicators (KPIs)
- **Total Revenue:** $817,860
- **Average Order Value:** $38.31
- **Total Pizzas Sold:** 49,574
- **Total Orders:** 21,350
- **Average Pizzas Per Order:** 2.32

## Project Analysis
- Daily and hourly order trends
- Sales by pizza category and size
- Best-selling and worst-selling pizzas
- Revenue and order performance
- Interactive dashboard filtering

## Key Insights
The dashboard helps identify popular pizza products, high-demand periods, and sales trends to support better business decisions.
